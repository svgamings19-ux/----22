# Этап 2. Шаблоны и первый интерфейс

## Реализация практических заданий

1. Код разделён на обработчики, модели, HTML-шаблоны и статические файлы. `cmd/expenses` содержит точку входа; `internal/app` запускает сервер.
2. `models.Expense` содержит `Amount`, `Description`, `Date`. Сумма представлена целым количеством копеек; дата — `time.Time`. Обработчик хранит записи в `[]models.Expense`. База данных и запись на диск отсутствуют.
3. Шаблон `expenses.html` выводит строки таблицы циклом `{{range .Expenses}}`. При пустом списке условие `{{if .Expenses}}` показывает приглашение добавить запись.
4. `layout.html` определяет общую страницу через `{{define "layout"}}`: шапку, меню, CSS, содержимое и подвал. Вызов `{{template "content" .}}` подставляет содержимое нужной страницы. Для каждой страницы отдельно разбираются layout и её шаблон через `ParseFS`, поэтому определения `content` не перезаписывают друг друга.
5. Форма передаёт сумму, описание и дату методом POST на `/expenses/new`. `r.ParseForm()` разбирает форму, `r.PostFormValue()` читает значения именно из тела запроса. После проверки обработчик добавляет запись в срез и вызывает `http.Redirect` со статусом 303 на список трат.

## Почему нужен Post/Redirect/Get

Браузер отправляет POST с данными формы. Сервер сохраняет запись и отвечает `303 See Other` с `Location: /expenses`. Браузер выполняет GET и показывает список. Обновление страницы теперь повторяет GET, а не добавляет ещё одну запись. Повторное отдельное нажатие отправки формы не является обновлением списка и может создать другую запись.

## Почему html/template безопаснее склейки строк

Пакет учитывает контекст HTML и автоматически экранирует данные. Например, описание `<script>alert(1)</script>` отображается как обычный текст, а не исполняемый скрипт. При прямой склейке строк такой ввод может стать HTML-кодом и привести к XSS. В проекте пользовательские значения остаются строками и не преобразуются в `template.HTML`.

## Проверка вручную

Откройте список, добавьте через форму «Продукты», сумму 1250.50 и дату. Убедитесь, что после сохранения адрес меняется на `/expenses`, а строка появляется в таблице. Обновите страницу и проверьте, что количество записей не изменилось. Перезапустите сервер: список должен очиститься.
