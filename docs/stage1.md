# Этап 1. Основы Go и HTTP

## Запуск в РЕД ОС

Установите Go из доступного репозитория вашей версии РЕД ОС (`sudo dnf install golang`) либо с официального сайта https://go.dev/dl/. Проверьте `go version`: для проекта нужен Go 1.22 или новее. Проект использует только стандартную библиотеку.

```bash
git clone https://github.com/svgamings19-ux/----22.git
cd -- ----22
go version
go run .
```

Откройте http://localhost:8080, http://localhost:8080/about и http://localhost:8080/ping в браузере. Для остановки нажмите Ctrl+C.

Модуль уже создан, его имя и минимальная версия Go находятся в `go.mod`. При создании нового проекта такой файл создаётся командой `go mod init github.com/svgamings19-ux/----22/expenses`; повторять её в готовом проекте не нужно.

## Проверка через curl

В другом терминале:

```bash
curl -i http://localhost:8080/
curl -i http://localhost:8080/about
curl -i http://localhost:8080/ping
curl -i -X POST http://localhost:8080/ping
```

Первые три запроса возвращают 200 OK. `/ping` возвращает `pong`, POST — 405 Method Not Allowed с заголовком `Allow: GET`. Параметр `-i` показывает статус и заголовки вместе с телом ответа. Автоматическая проверка: `go test ./...`.

## Как обрабатывается запрос

1. `package main` и `func main()` задают исполняемую программу и её точку входа. `http.ListenAndServe` слушает порт 8080 и передаёт запросы маршрутизатору.
2. `http.ServeMux` выбирает обработчик по пути запроса. `HandleFunc` регистрирует функцию как HTTP-обработчик.
3. `*http.Request` содержит метод, URL, заголовки и тело запроса. Обработчик `/ping` проверяет метод: только GET разрешён.
4. Через `http.ResponseWriter` обработчик задаёт заголовки, статус и тело ответа. Заголовки нужно устанавливать до записи тела. Первая запись тела без явного `WriteHeader` означает статус 200. Если обработчик вообще ничего не запишет, после его завершения клиент получит пустой ответ со статусом 200.
5. Сервер отправляет ответ клиенту. Браузер отображает текст, curl позволяет увидеть и текст, и HTTP-заголовки.

GET служит для получения данных, POST — для отправки данных с изменением состояния, например добавления траты. Статусы: 200 — успех; 302 — временное перенаправление; 400 — некорректный запрос; 404 — неизвестный путь; 405 — запрещённый для пути метод; 500 — внутренняя ошибка сервера.

Этот отчёт относится к версии этапа 1. В этапе 2 главная страница и `/about` становятся HTML-страницами, а контракт `/ping` сохраняется.
