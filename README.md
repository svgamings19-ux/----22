# Учёт личных трат

Веб-приложение на Go: регистрация и вход, личные расходы с CRUD, категории,
фильтры по датам, статистика Chart.js и экспорт CSV. SQLite создаётся и
обновляется миграциями при запуске. Шаблоны и CSS/JS встроены в приложение.

## Запуск

Нужен Go 1.26 или новее (проверено на Go 1.27.2). Компилятор C не требуется.

1. Скопируйте `.env.example` в `.env` в корне проекта.
2. Замените `SESSION_SECRET` случайной строкой длиной минимум 32 байта.
   Пример генерации в PowerShell:

   ```powershell
   $bytes = New-Object byte[] 32
   $rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
   $rng.GetBytes($bytes)
   [Convert]::ToBase64String($bytes)
   $rng.Dispose()
   ```

3. Запустите из корня проекта:

   ```sh
   go run .
   ```

Откройте http://localhost:8080 (или свой `PORT`), зарегистрируйтесь и войдите.
Остановка: Ctrl+C. Альтернативная точка входа: `go run ./cmd/expenses`.

| Переменная | Назначение |
| --- | --- |
| `PORT` | Обязательный порт, 1–65535 |
| `DB_PATH` | Обязательный путь к SQLite; родительская папка должна существовать |
| `SESSION_SECRET` | Обязательный случайный секрет; смена завершает все сессии |
| `COOKIE_SECURE` | `false` для локального HTTP; `true` при работе через HTTPS |
| `SESSION_TTL` | Срок сессии, по умолчанию `168h`; от `1m` до `720h` |

Переменные окружения имеют приоритет над `.env`. Для публикации используйте
HTTPS через обратный прокси и `COOKIE_SECURE=true`. `.env` и базы данных не
добавляются в Git. Ограничитель попыток входа хранится в памяти одного процесса.

Суммы хранятся в копейках; интерфейс и CSV используют рубли. CSV выгружается
в UTF-8 с BOM, разделителем `;` и защитой текстовых ячеек от формул.
Ссылка «Скачать выборку CSV» учитывает текущие фильтры.
Для диаграмм нужен доступ к CDN Chart.js; числовые таблицы статистики работают
и при недоступной библиотеке графиков.

## Проверка

```sh
go test ./...
go vet ./...
go build ./...
```

Тесты используют временные базы: проверяют CRUD, фильтры, сохранение данных,
изоляцию пользователей, сессии, CSRF, валидацию, статистику, CSV и обработку паники.
